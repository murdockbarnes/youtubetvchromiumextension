# 🛡️ Security Policy

The **YouTube TV for Chromium-based Browsers** team takes the security of our users very seriously. This document outlines our supported versions and how you can responsibly report security vulnerabilities.

## 📌 Supported Versions

We currently provide active security updates and patches for the following versions of the extension. We highly recommend always running the latest stable build.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

# 🚨 Reporting a Vulnerability

If you discover a security vulnerability, flaw, or potential exploit within this extension, please follow these steps to responsibly disclose it:

1. **Keep it private:** Please do **not** open a public GitHub issue. This ensures malicious actors cannot exploit the vulnerability before a patch is released.
2. **Contact the Developer:** Report the issue directly and privately by emailing **[Your Email Here]** (or contact Scott Allan directly).
3. **Include details:** Please provide a clear description of the vulnerability, exact steps to reproduce it, and any relevant screenshots or logs.

### ⏳ What to Expect Next
- We will prioritize your report and aim to acknowledge receipt within **48 hours**.
- We will work closely with you to understand the issue, verify it, and develop a rapid patch timeline.
- Once the vulnerability is fully patched and the updated .crx is deployed, we will publicly disclose the issue in our Release Notes and (with your permission) credit you for the responsible disclosure!
